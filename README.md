# Front-end Project Boilerplate Generator

Generate boilerplate codes for building front-end application. 

Start a React, Vue or Svelte project and choose a bundler: Webpack, Parcel, or Rollup. Seamlessly add UI libraries, testing frameworks, linters, and transpilers—with all configurations automatically set up for you.

> [Vite](https://vite.dev) is the easiest and most reliable option to start a new front-end project. It has gained significant popularity in front-end development due to its focus on speed, efficiency, and modern development practices. If you want to build a full-stack React applications, [React Router](https://reactrouter.com/) can also be another good option, it offers advantages beyond just client-side routing. [Rspack](https://rspack.rs/) (one of my favorites) offers lightning-fast build times due to its Rust foundation and optimized parallel architecture, making it an excellent modern alternative to Webpack
